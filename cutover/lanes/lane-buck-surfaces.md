## ⚠️ Gotchas — break these and the live site breaks
- **app-mobile-fixes.js** is a live-domain CSS guard injected via pwa.js — a stale copy here can
  OVERRIDE a lane's correct mobile CSS. Check it first when a mobile breakpoint renders wrong.
- **mobile-hub.css** MUST be a media-gated `<link>` in `<head>` (no-flash law); never inject via pwa.js.
- The **#ntm-form composer markup is SHARED** — hub-polish.js reads `#ntm-forum`; desktop + mobile both
  depend on it. Announce any shared-markup change.
- The overlay fork (`hub-overlay-flag/*.js` in the bespoke-cutover worktree) is STALE vs the live
  `/var/www/dev/*.js` — LIVE is the source of truth; never `cp` the fork over live.
- **shop-img is regenerated by the shop-feed refresh** (re-bloats the logo to 969px — that's what swept
  the coordinator's resize on 6/13 21:07). Durable logo fix lives in buck's shop-feed generator.
